Jordan gave direct, critical feedback: the eagle art is too detailed/gradient-heavy to hold up at favicon size or in one color, the wordmark is a completely different visual style from both the eagle and the site's existing fonts, and the cut-off "Homes" text is a Canva export issue Jeff likely can't clean up himself in GIMP/Inkscape. The play: let him keep tinkering and send it over to implement as-is if he wants — but the real pitch on the table is a proper logo package built together with matching site fonts. Pitched, not priced, no decision yet.

Keep "by appointment only" language anywhere location gets referenced, including the About page's planned showroom section (Pittsville) and any future gallery or category pages.

Jordan manages workload by scope and budget across roughly 6–7 concurrent clients, not a fixed headcount — already communicated to Jeff directly. Useful framing if Jeff pushes for a faster timeline than the queue allows once he approves something.
