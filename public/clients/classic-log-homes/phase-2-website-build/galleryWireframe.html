Opens directly to the photo that was clicked — not the first photo in the album. Title and description sit between the photo and the thumbnail strip, same as the current site's viewer. ✓ Confirmed Decisions
  • ✅
    Replaces the Facebook Link — Gallery keeps portfolio content and its SEO value on-site instead of sending visitors out to Facebook.
  • ✅
    Self-Serve Albums — Albums are a dedicated CMS document type, not a hardcoded set. Jeff creates, edits, and removes albums himself anytime.
  • ✅
    Dynamic, Indexable Album Pages — One real, crawlable URL per album at /gallery/[album-slug], same template reused for every album — same pattern as Floor Plan Detail.
  • ✅
    Description Doubles as SEO Copy — Each album's description is both visible copy and the source for photo alt text and on-page SEO.
  • ✅
    Built for Scale — Photo grid supports pagination or lazy-loading from launch, even though initial content is small — some albums will grow past 100 photos.
  • ✅
    Lightbox Is Reused, Not Redesigned — Same component and visual style as the current live site, wired up to new album photo data. Each photo carries its own heading and description caption, shown between the photo and the thumbnail strip.
  • ✅
    Keywords Are Hidden Metadata Only — Searchable for Jeff's own internal use. No public tag or filter UI anywhere in this flow.
  • ✅
    General Portfolio, Not Plan-Specific — Gallery photos are a general project portfolio, not tied to individual floor plans.
